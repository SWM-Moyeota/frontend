# Play 스토어 등록정보 자료

`스토어 설정 → 기본 스토어 등록정보` 에 그대로 올리는 것들. 만든 스크립트는 세션 임시
디렉터리에 있었으므로, 다시 만들어야 하면 아래 「다시 만들 때」를 보라.

## 파일

| 파일 | 어디에 | 규격 |
|---|---|---|
| `00-logo-source-512.png` | — (디자인 원본) | 512×512 PNG · 아래 모든 아이콘의 출처 |
| `01-icon-512.png` | 앱 아이콘 | 512×512 PNG (앱의 `ic_launcher-playstore.png` 복사본) |
| `02`~`09-screenshot-*.png` | 휴대전화 스크린샷 | 1080×1920 (9:16) · 8장 |
| `10-feature-graphic-1024x500.png` | 그래픽 이미지 | 1024×500 |

**원본 스크린샷은 `_workspace/landing/assets/shots/` 의 648×1440 webp 다.** 그 비율은
9:20 이라 Play 가 요구하는 **9:16 을 벗어난다** — 그래서 1080×1920 캔버스에 브랜드
색(`#085AF5`, `MoyeotaColor.Primary500`) 배경을 깔고 가운데 얹었다. 잘라서 맞추면
화면 내용이 잘리므로 여백을 주는 쪽을 골랐다.

## 문구

**간단한 설명** (80자 제한)

```
같은 방향으로 가는 사람을 모아 택시 한 대를 나눠 타요. 택시비, 혼자 다 내지 마세요.
```

**자세한 설명**은 `_workspace/play-store-listing.md` 에 있다.

## 고칠 때 주의

- **스크린샷 캡션과 스토어 설명이 같은 말을 해야 한다.** 랜딩 페이지
  (`_workspace/landing/index.html`)도 같은 문장을 쓴다 — 한 곳만 고치면 어긋난다.
- **「만 14세」가 설명문에 있다.** 가입 최소 연령을 바꾸면(`domain` 의 `Auth.MIN_AGE`)
  설명문·처리방침·약관을 **같이** 고쳐야 한다.
- 화면을 다시 찍으면 **하단 탭바가 잘리지 않는지** 확인할 것. 처음 만들 때 아래를 잘라
  '이어지는 느낌'을 주려다 탭바가 반만 보여 미완성처럼 읽혔다.

## 로고를 바꿀 때

`00-logo-source-512.png` 를 새 512×512 PNG 로 갈아끼우고 `make-icons.py` 를 돌리면
런처 아이콘 15개 + Play 아이콘 2개가 한 번에 다시 만들어진다.

```
python3 _workspace/play-assets/make-icons.py
```

스크립트가 하는 일:

1. **테두리 6px 평균으로 배경색을 구한다.** 그 값을 `values/colors.xml` 의
   `ic_launcher_background` 에 **직접 넣어야 한다** — 스크립트는 값을 출력만 한다.
   적응형 아이콘의 배경 레이어가 이 색이라, 안 맞추면 마크 둘레에 색 띠가 생긴다.
2. **마크만 분리한다.** 원본은 불투명 한 장이라 배경을 지워야 foreground 가 된다.
   순수색 2개를 k-means 로 찾고, 배경에서 3px 넘게 떨어진 픽셀은 불투명 고정,
   경계의 안티앨리어싱 띠만 피복률을 역산한다. 전역 임계값 한 개로 자르면 어두운
   쪽 색이 통째로 반투명해진다.
3. **적응형 foreground 는 마크를 축소해 올린다** (`FG_RADIUS_RATIO = 0.32`).
   108dp 캔버스에서 마크 외접원이 64%가 되는 값 — 72dp 마스크 원(66.7%) 안쪽이다.
   **원본을 그대로 쓰면 안 된다**: 이 로고는 외접원이 78.6%라 원형 마스크에서
   양 끝이 잘린다.
4. 레거시 `ic_launcher` 는 원본 풀블리드 축소, `ic_launcher_round` 는 원형 크롭.
   `minSdk = 24` 라 API 24·25 에서 실제로 쓰인다 — 지우면 안 된다.

검산 두 줄이 출력된다. **재합성 오차**(마크를 배경색 위에 다시 얹어 원본과 비교)와
**알파 분포**(반투명이 경계 띠 수준인지). 오차가 수천 픽셀로 번지면 배경 키잉이
깨진 것이다.
