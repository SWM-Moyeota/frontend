# 67 · 채팅 키보드 가림 · 배너 토글 찌그러짐 · 운행중 버튼 고정폭

작성 2026-09-13. 실기 피드백 3건 중 2·3번(1번 「동승자 실시간 위치」는 별도).

## 1. 채팅 입력창이 키보드에 가림
- 원인: `enableEdgeToEdge()` 를 쓰는데 액티비티가 기본 `adjustResize` 라 **창이 일부만 줄고**(실측: 2400 → 1822px, 키보드는 876px) 나머지는 키보드에 덮였다. 거기에 `imePadding()` 을 더하면 **이중 보정**이 되어(창 1822 − IME 876 = 946) 입력창과 키보드 사이에 485px 빈 칸이 생겼다.
- 수정: `MainActivity` 에 `android:windowSoftInputMode="adjustNothing"` — 창은 절대 줄지 않고 **키보드 보정의 출처를 `imePadding()` 하나로 통일**한다.
  - 채팅: 루트에 `imePadding()`, 키보드가 뜨면 하단탭을 숨긴다(키보드 위 탭바는 대화 높이만 깎는다), 메시지 목록은 새 메시지·키보드 등장 때 항상 맨 아래로 스크롤.
  - **입력이 있는 나머지 8화면**(15 목적지 · 04a 로그인 · 10 프로필 · 06 학교메일 · 07 인증코드 · 08 재직 · 09 본인확인 · 31 결제추가)에도 루트 `imePadding()` 추가 — `adjustNothing` 은 앱 전역이라 이들도 스스로 비켜야 한다.

## 2. 「실시간 위치 공유 중」 배너의 토글이 작게 보임
- 원인: 배너 Row 가 `문구 + 문구 + Spacer(weight) + 토글` 인데 두 문구에 weight·말줄임이 없어 좁은 폰에서 Row 가 넘쳤다. Compose 는 남는 폭을 뒤 자식부터 깎으므로 **마지막 자식인 토글이 0dp 로 찌그러진다.**
- 수정: 문구 묶음을 `weight(1f)` Row 로 감싸고 부제에 말줄임. 토글은 항상 46dp. 좌우 여백 28 → 20dp. 위의 「매칭 화면으로 →」 배너도 같은 형태라 함께 고쳤다.

## 3. 26 운행 중 「신고」·「채팅 열기」 고정폭
- `size(width = 112.dp)` · `size(width = 176.dp)` + `Spacer(weight)` — 같은 이유로 좁은 폰에서 찌그러진다. 남는 폭을 `weight(0.39f)` / `weight(0.61f)` 로 나누고 간격 12dp.
